# Custom Hooks (`hooks/`)

Kumpulan React custom hooks reusable untuk kebutuhan antarmuka (state sesi, pagination cursor, deteksi viewport mobile, dan sinkronisasi formulir).

- Berisi `use-mobile.ts` (bawaan workspace).
- Hooks baru akan ditambahkan pada Tahap 6 dengan penamaan `use-<nama>.ts` atau `camelCase`.
