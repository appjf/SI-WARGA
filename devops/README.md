# DevOps & Infrastructure (`devops/`)

Dokumentasi operasional infrastruktur, deployment, template konfigurasi lingkungan, dan pemantauan sistem.

## Subdirektori

- `deployment/` — Panduan deployment Vercel (Web Next.js) dan hosting container Python (GIS FastAPI + PostGIS).
- `environment-templates/` — Dokumentasi daftar variabel lingkungan per tahap (`local`, `development`, `staging`, `production`).
- `monitoring/` — Konfigurasi observability, health check, alerting, serta jadwal verifikasi backup.
