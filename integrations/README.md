# External & Cloud Integrations (`integrations/`)

Dokumentasi spesifikasi, kontrak keamanan, dan alur integrasi GGR-ICMS dengan layanan eksternal.

## Subdirektori

- `firebase/` — Firebase Authentication, Cloud Firestore, Firestore Security Rules, dan FCM.
- `google-drive/` — Google Drive API untuk arsip dokumen privat yang dimediasi backend.
- `external-services/` — Layanan pendukung lainnya (penyedia basemap, email/notifikasi, atau webhook masa depan).
