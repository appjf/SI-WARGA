# Styles & Design Tokens (`styles/`)

Dokumentasi dan definisi design token visual berdasarkan `05-UI-UX-Design-System.md`.

## Acuan Token Awal

- **Primary:** `#1F5E4A` (Aksi utama)
- **Secondary:** `#D9A441` (Aksen)
- **Background / Surface:** `#F7F8F6` / `#FFFFFF`
- **Status:** Success `#217A45`, Warning `#A15C00`, Danger `#B42318`
- **Tipografi & Spasial:** Skala jarak berbasis `4px`, radius kartu `12px`, maksimal dua keluarga font.

*Catatan: Implementasi styling global saat ini menggunakan Tailwind CSS v4 pada `app/globals.css`.*
