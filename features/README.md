# Domain Features (`features/`)

Modul fitur frontend yang diorganisasi berdasarkan domain bisnis GGR-ICMS.

## Daftar Modul Domain

- `auth/` — Alur login, logout, dan status verifikasi akun.
- `residents/` — Profil warga dan pengajuan koreksi data mandiri.
- `households/` — Informasi rumah tangga dan unit rumah (`houseCode`).
- `administration/` — Formulir permohonan surat, pelacakan status, dan antrean verifikasi.
- `finance/` — Ringkasan kas sesuai izin, riwayat iuran, pencatatan transaksi, bukti, dan reversal.
- `complaints/` — Pengajuan tiket pengaduan, lokasi opsional, dan tindak lanjut PIC.
- `announcements/` — Pengumuman dan kalender agenda kegiatan warga (`Asia/Jakarta`).
- `assets/` — Inventarisasi prasarana lingkungan dan jadwal inspeksi.
- `security-incidents/` — Pencatatan kejadian keamanan dan patroli terbatas.
- `gis/` — Eksplorasi layer peta interaktif, pencarian kode objek, dan alternatif daftar fitur.
- `documents/` — Antarmuka unggah/unduh berkas aman yang dimediasi backend.
- `audit/` — Antarmuka baca-saja penelusuran audit untuk auditor dan super admin.
