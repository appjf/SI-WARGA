# Public Static Assets (`public/assets/`)

Direktori aset statis publik untuk antarmuka web (logo resmi lingkungan, ikon marker peta, dan ilustrasi antarmuka non-sensitif).

## Aturan

- Dilarang menyimpan dokumen warga, foto bukti transaksi, atau foto inspeksi privat di direktori `public/`. Seluruh berkas privat disimpan di Google Drive melalui backend.
- Dokumen referensi proyek dari paket implementasi berada di `public/assets/aistudio/`.
