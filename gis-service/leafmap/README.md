# Leafmap Analytics & Thematic Mapping (`gis-service/leafmap/`)

Direktori notebook dan worker Python berbasis Leafmap (serta Rasterio bila data raster tersedia) untuk:
- Eksplorasi dan verifikasi visual data survei sebelum dipublikasikan ke PostGIS.
- Pembuatan peta tematik kondisi jalan, drainase, sebaran pengaduan, dan prioritas inspeksi untuk laporan berkala.

*Catatan: Tidak digunakan sebagai pengganti renderer peta browser interaktif maupun solver hidraulika teknik.*
