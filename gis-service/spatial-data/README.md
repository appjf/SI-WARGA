# Spatial Data Repository (`gis-service/spatial-data/`)

Direktori penyimpanan dataset spasial tervalidasi (GeoJSON/GeoPackage) dan metadata survei lapangan (kode unit, akurasi GPS, sumber akuisisi, tanggal verifikasi).

*Peringatan: Hanya menyimpan data non-PII yang telah disetujui atau data sintetis untuk pengujian.*
