# Layouts (`layouts/`)

Kerangka tata letak halaman berdasarkan konteks pengguna dan peran akses.

## Rencana Layout

- `PublicLayout` — Tata letak informasi umum sebelum login.
- `AuthLayout` — Tata letak terfokus untuk proses masuk dan status aktivasi akun.
- `ResidentLayout` — Navigasi mobile-first (bottom nav / drawer) untuk layanan warga.
- `ManagementLayout` — Ruang kerja operasional pengurus dengan menu dinamis sesuai peran.
