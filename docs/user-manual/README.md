# User Manual (`docs/user-manual/`)

Direktori panduan penggunaan sistem dalam Bahasa Indonesia yang jelas dan mudah dipahami untuk setiap kelompok pengguna:
- Panduan Warga (layanan administrasi, pengaduan, iuran, peta lingkungan).
- Panduan Ketua RT & Sekretaris (verifikasi warga, persetujuan surat, pengumuman).
- Panduan Bendahara (pencatatan, bukti, rekonsiliasi, reversal).
- Panduan Petugas Keamanan & Koordinator GIS/Aset.
- Panduan Administrator & Auditor.
