# Pusat Dokumentasi (`docs/`)

Dokumentasi resmi GGR-ICMS yang disusun berdasarkan Implementation Package v1.0.

## Subdirektori

- `architecture/` — System Architecture Document (SAD) dan Architecture Decision Records (ADR).
- `requirements/` — SRS, Product Backlog, Traceability Matrix, dan Decision Log.
- `database/` — Rancangan Firestore, PostgreSQL/PostGIS, kamus data, dan strategi migrasi.
- `api/` — Spesifikasi API aplikasi & GIS serta kontrak OpenAPI.
- `gis/` — Arsitektur GIS, SOP survei lapangan, klasifikasi layer, dan standar CRS.
- `security/` — Desain autentikasi, RBAC, Security Rules, dan checklist kepatuhan privasi/UU PDP.
- `operations/` — Operations Runbook, strategi backup/restore, Disaster Recovery, dan respons insiden.
- `user-manual/` — Panduan operasional pengguna untuk Warga dan Pengurus RT.

*Catatan: Berkas sumber asli paket implementasi tersimpan sebagai lampiran di `public/assets/aistudio/`.*
